# 渠道报价规范 v1 —— 《电脑购买大世界》

> 目标：把「一个参考价」升级成「多平台 × 多店铺 × 可验证」的报价，并按**权威可靠 + 售后**排序。
> 采集者必读。本文件为硬性规范。

## 一、背景（为什么这么做）

京东/淘宝商品页的实时价需要登录、有反爬（滑块验证），无法稳定直连抓取。
可行且可追溯的方式：用**逛丢（guangdiu.com）**的折扣聚合页——它收录京东/天猫的**活动到手价**，页面里同时给出：
平台（京东/天猫）、是否自营、店铺名（如「华硕京东自营官方旗舰店」「天猫数码家电自营旗舰店」）、活动描述（含国补/PLUS/88VIP 等）、活动日期、商品直达链接。

**所以：每条报价 = 平台活动快照，不是平台实时价。** 必须如实标注快照日期，并提示「下单前以平台页面为准」。

## 二、采集边界（硬性）

1. 只采集 `data/band-N.json` 中已存在机型的报价，按 `laptopId` 关联；**不要新增机型**。
2. **只访问逛丢搜索结果页**：
   - `https://guangdiu.com/search.php?q=<关键词>`（全部平台）
   - `https://guangdiu.com/search.php?m=京东自营&q=<关键词>`
   - `https://guangdiu.com/search.php?m=天猫&q=<关键词>`
   **不要访问 `detail.php` 详情页**（会触发滑块验证，浪费额度）。
3. 遇到「安全验证 / 请按住滑块」页面：立即停止该关键词，改用 `web_search` 找同款别的关键词，不要连续重试。
4. **不要编造**：价格、店铺名、日期都必须是页面上真实出现的文本。查不到就写 `null` 或标 `待核实`。
5. 优先取**最新**的活动（越接近 2026-11-17 越好）；若最新活动早于 2026-09-01，仍可收录但 `stale=true`。
6. 每条报价必须能对应到「同型号 + 同配置」：标题里的 CPU/GPU/内存/硬盘/屏幕规格要与机型一致，不能把同系列低配价套给高配。

## 三、文件格式

`data/channels/band-1.json` ~ `band-4.json`（每个采集者一个文件，互不重叠）

```json
{
  "band": 1,
  "collectedAt": "2026-11-17",
  "collector": "channel-band1",
  "items": [
    {
      "laptopId": "honor-magicbook-x16-2026",
      "searchKeyword": "荣耀 MagicBook X16 2026",
      "offers": [
        {
          "platform": "京东",
          "storeType": "京东自营",
          "storeName": "荣耀京东自营旗舰店",
          "price": 4299,
          "priceKind": "到手价",
          "priceNote": "京东活动售价4499元，国补15%后实付4299元",
          "publishedAt": "2026-11-10",
          "stale": false,
          "url": "https://item.jd.com/xxxx.html",
          "evidenceUrl": "https://guangdiu.com/detail.php?id=30285240",
          "services": ["国补", "京东物流", "7天无理由", "白条免息"],
          "status": "已核实"
        }
      ],
      "note": "该机型天猫旗舰店未检索到 9 月以来活动"
    }
  ]
}
```

## 四、字段枚举

| 字段 | 取值 |
|---|---|
| `platform` | `京东` / `天猫` / `淘宝` / `拼多多` / `品牌官网` / `其他` |
| `storeType` | `京东自营` / `京东官方旗舰店` / `京东第三方` / `天猫官方旗舰店` / `天猫自营` / `淘宝店铺` / `拼多多百亿补贴` / `品牌官网` / `未知` |
| `priceKind` | `到手价` / `券后价` / `国补后` / `活动价` / `页面价` |
| `services` | 从页面文本提取，只能取：`国补` `学生认证` `PLUS会员` `88VIP` `白条免息` `以旧换新` `晒单返现` `赠品` `京东物流` `7天无理由` `运费险` `上门服务` `全国联保` |
| `status` | `已核实`（价格+日期+平台都来自页面）/ `部分待核实`（缺店铺名或日期）/ `待核实`（只有价格） |
| `stale` | `true` 表示活动早于 2026-09-01，价格很可能已变 |

## 五、怎么判断 storeType

- 逛丢条目右侧有「京东 · 自营」→ `京东自营`
- 描述里出现「京东XX官方旗舰店」「京东自营官方旗舰店」→ `京东官方旗舰店`（若同时标自营则算 `京东自营`）
- 天猫侧出现「天猫XX自营旗舰店」→ `天猫自营`
- 天猫侧出现「XX官方旗舰店」「天猫商城」→ `天猫官方旗舰店`
- 描述只写「京东此款…」且无自营/旗舰店字样 → `京东第三方`（不确定就 `未知`，在 note 说明）
- 拼多多条目 → `拼多多百亿补贴`

## 六、怎么提价格

优先取**最终实付/到手价**（描述里的「实付低至X元」「到手价X」「券后X元」），`priceKind` 对应填写，并在 `priceNote` 里保留原价与优惠链条（照抄页面，不要改写数字）。
标题价格与描述价格冲突时，以**描述里的实付价**为准，并在 note 说明冲突。

## 七、每台的目标

- 至少 **1 条**报价；尽量 **2 条**（京东自营 + 天猫官方旗舰店各一）。
- 同一机型同一平台最多留 **2 条**（最新 + 次新），不要堆旧活动。
- 优先覆盖「京东自营 / 天猫官方旗舰店」，其次「京东官方旗舰店」，第三方店只作补充。
