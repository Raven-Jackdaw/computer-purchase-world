# 电脑购买大世界 · Computer Purchase World

> 一台笔记本的暗黑选购指南：把 64 台学生笔记本变成可以逛的哥特世界——勾选条件，世界重排，选出你的那台。

![世界视图](docs/screenshot-world.png)

一个**单文件 Web 应用**（HTML + CSS + JS，零前端依赖），附带**可选的本地实时价格服务**（Node.js）。
数据采集于 **2026-11-17**：**64 台机型 / 4 个价位段 / 7 条榜单 / 82 条渠道报价**。

## ✨ 功能

- **世界视图**：按「预算大陆」（学徒区 ≤¥4,499、主力区 ¥4,500–5,999、进阶区 ¥6,000–7,999、秘境 ≥¥8,000）、用途场景、品牌、CPU、显卡、内存、屏幕、重量、接口等条件筛选，结果按适配度排序
- **排行榜**：综合实力 / 性价比 / 性能 / 便携 / 屏幕 / 续航 / 扩展 —— 7 条榜单，可切换价位段与品类（轻薄本 / 全能本 / 游戏本 / 二合一）
- **上市时间线**：按上市年月倒序，新机与上代降价机对照
- **选购须知**：7 类用途的规格底线、18 条避坑、购买时机、31 条参数黑话
- **详情抽屉 + 对比**：逐项参数、优缺点、渠道报价，支持多台并排对比
- **分享与导出**：筛选结果可复制分享链接、Top10 清单复制、结果导出 TXT / JSON
- **主题切换**：黑夜 / 烛光羊皮纸；带开场「守夜人」与动画彩蛋
- **本地实时市场价（可选）**：启动本地服务后，页面一键刷新 64 台机器的渠道报价（京东自营 / 天猫等，含链接与时间）
- **数据质量保障**：构建时校验字段 / 价格段 / 渠道匹配，附带引擎与数据自检

## 🚀 快速开始

### 方式一：直接打开（零依赖，最快）
双击 `dist/电脑购买大世界.html`，用浏览器打开即可 —— 数据、样式、脚本全部内联在这个单文件里。

### 方式二：本地实时价格（可选）
需要 Node.js 18+：

```bash
node server.mjs
# 或者 Windows 下双击「启动实时价格.bat」
```

然后浏览器打开 <http://127.0.0.1:8787/>，点右上角「刷新市场价」。
> 说明：静态 HTML 打开时显示的是**快照价**；启动本地服务后才能刷新渠道报价。

### 方式三：自行构建

```bash
node build.mjs              # 产物：dist/电脑购买大世界.html
node test/engine.test.mjs   # 运行引擎与数据自检
```

## 📁 项目结构

```
电脑购买大世界/
├─ dist/
│  └─ 电脑购买大世界.html        # 构建产物（单文件，双击即用）
├─ src/
│  ├─ index.html               # 页面骨架
│  ├─ styles.css               # 暗黑哥特主题样式
│  ├─ engine.js                # 筛选引擎 / 榜单 / 适配度 / 格局数据
│  ├─ app.js                   # 视图渲染与交互（世界 / 排行榜 / 时间线 / 选购须知）
│  ├─ avatar.js                # 守夜人头像（内联 data URI）
│  ├─ banner.js / sprite.js    # 开场动画与卡片画面
├─ data/
│  ├─ band-1..4.json           # 四个价位段的机型数据（共 64 台）
│  ├─ channels/band-1..4.json  # 渠道报价（82 条）
│  ├─ knowledge.json           # 规格底线 / 避坑 / 购买时机 / 黑话 / 来源
│  ├─ live/market.json         # 最近一次实时市场价快照
│  └─ seed.json                # 开发用种子数据（正式构建不会使用）
├─ spec/                       # 数据与渠道报价规范文档
├─ test/engine.test.mjs        # 自检脚本
├─ tools/probe-guangdiu.cjs    # 价格聚合页探测工具（开发用）
├─ build.mjs                   # 构建：校验数据 → 内联为单文件 HTML
├─ refresh.mjs                 # 实时价格刷新器（抓取公开聚合页 → 渠道报价）
├─ server.mjs                  # 本地实时价格服务（127.0.0.1:8787）
└─ 启动实时价格.bat            # Windows 一键启动本地服务
```

## 🗂 数据说明
